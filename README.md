# 📊 Vendor Evaluation & Ranking Dashboard (Excel Project)

## 📌 Project Overview
This project is a fully automated Microsoft Excel-based **Vendor Evaluation, Eligibility Assessment, and Performance Ranking System** designed for business decision-making.

It simulates a real-world procurement and analytics workflow used in organizations to evaluate vendors based on eligibility, technical performance, and financial scoring.

---

## 🎯 Objective
To build a structured Excel system that:
- Evaluates vendor eligibility
- Calculates technical and financial scores
- Generates final rankings
- Provides an interactive executive dashboard for decision-making

---

## 📁 Project Structure (Sheets Included)

### 1. Raw_Data
- Contains 100+ simulated vendor/company records
- Includes company details such as industry, revenue, region, and employees

### 2. Eligibility_Check
- 8 mandatory eligibility criteria
- Automated qualification logic:
  - If ANY condition fails → **Disqualified**
  - If ALL conditions pass → **Qualified**

### 3. Technical_Scoring
- Evaluation based on:
  - Experience
  - Team Strength
  - Project Delivery
  - Quality Metrics
- Weighted scoring system (out of 100)

### 4. Financial_Evaluation
- Bid price comparison
- Normalized scoring model
- Lowest bid analysis

### 5. Final_Ranking
- Combined scoring model:
  - 70% Technical Score
  - 30% Financial Score
- Final ranking of all vendors

### 6. Dashboard
Interactive executive dashboard featuring:
- KPI Cards (Total Vendors, Qualified, Disqualified, Avg Score)
- Qualification Status Chart
- Top 10 Vendors Ranking
- Score Distribution Analysis
- Interactive filters (Slicers)
